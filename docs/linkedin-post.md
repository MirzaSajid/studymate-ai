I just wrapped up Module 5 of my AI program: exploring AI tools and building a mini project. Here is what I learned. 🚀

🔍 What I explored
I used ChatGPT, Google Gemini and Microsoft Copilot for three things: writing and debugging code, researching topics faster, and planning my work. Each one has strengths, and comparing them taught me how much the quality of my prompt shapes the quality of the answer.

🛠️ What I built
StudyMate AI: a web app where you paste your notes and get a summary, an interactive quiz, flashcards or a simple explanation, powered by the Gemini API.

Under the hood:
• Node.js backend that keeps the API key off the browser
• Structured JSON output, validated before it reaches the UI
• Input limits, rate limiting and XSS-safe rendering
• Automated tests (11 passing)

💡 My biggest takeaways
1. AI is a strong assistant, but not an autopilot. I reviewed and tested every line it helped me write.
2. Clear, specific prompts with a defined output format beat long, vague ones.
3. Never trust model output blindly. Validate it like any other user input.

As an AI student with a frontend background, this project showed me how both sides fit together: great interfaces and reliable AI behind them.
